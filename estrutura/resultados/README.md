# Resultados

Esta pasta guarda as saídas da avaliação do motor. Os arquivos usam ponto e vírgula como separador e vírgula como separador decimal.

O gabarito da Atividade 05 é uma versão inicial baseada no clube de origem. Ele serve para testar o pipeline e precisa ser substituído ou revisado por julgamentos humanos antes de uma conclusão sobre BM25 e TF-IDF.

Para atualizar os arquivos, execute o script de avaliação a partir da raiz do repositório.
